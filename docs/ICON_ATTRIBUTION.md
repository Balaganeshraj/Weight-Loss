# Icon attribution

Selected AndroidX Material icon vector sources are vendored under `app/src/main/java/androidx/compose/material/icons/`. Original copyright and Apache License 2.0 headers are retained. Only extended vectors actually used by the app are included; the Material core dependency supplies common icons.

Source artifact: `androidx.compose.material:material-icons-extended-android:1.7.8:sources`, downloaded from Google Maven over verified TLS and checked against its published SHA-256. This avoids including the entire extended icon library in development builds.
