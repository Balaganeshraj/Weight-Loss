# VELNUMI

**Your Life. In Balance.**

Implemented from the owner’s supplied logo and brand-board images. Spelling and tagline follow the owner’s text (the brand-board image contains a tagline typo).

| Token | Hex | Use |
|---|---|---|
| Crimson Red | #B3122F | Primary buttons, headings, selected controls |
| Ruby Red | #E63946 | Logo and decorative accents |
| Coral | #FF7A7A | Voice orb and decorative highlights |
| Blush | #F9D7D6 | Selected indicators and soft cards |
| Warm Off-White | #FCF6F4 | Light canvas and launcher background |
| Deep Plum | #3B1F2E | Main text and dark theme surfaces |

Soft rose/coral tints support distinct dashboard cards. White-on-crimson is used for primary buttons; ruby/coral are not used as small white-text button backgrounds. Dark screens use plum with blush text and accents. Promotion spaces retain the requested 16:9 ratio and rounded corners.

Native vector assets adapt the supplied folded V/leaf mark for Android rendering. They are a vector reconstruction, not an original exported production logo file. Launcher assets include adaptive foreground/background and an Android 13 monochrome layer; notifications use a solid monochrome mark. No raster image generation or replacement third-party logo was used.

Navigation follows the board: Today (home), Nutrition (apple), Move (runner), Plan (checked calendar), Sleep (crescent). Care/medication/report access remains under Sleep. Existing supplemental icons remain consistent line icons, tinted by the theme. The assistant and promotion placeholders remain demos.

Brand naming is applied to app label, header, onboarding, notifications, assistant, Health Connect disclosure, listing and delivery filenames. Internal package/class/database/encryption identities remain unchanged to protect update/data compatibility. Historical supplied VitalDay specifications remain preserved under docs/vitalday.

English and Tamil remain the only language choices. The brand name/tagline stay in English in both locales. Some older feature screens still contain English text; this rebrand does not claim complete Tamil localization.
